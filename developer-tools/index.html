What these developer tools cover

The daily chores of working with data and code: pasting a block of JSON to see it formatted and validated, encoding or decoding Base64 and URLs, reading the claims inside a JWT, testing a regular expression against sample text, generating UUIDs for database keys, hashing a string, diffing two versions of a text, converting a Unix timestamp, or designing a CSS gradient with a live preview.

Everything runs locally, which is the point for developer work: tokens, API payloads and config snippets are often sensitive, and these tools never send them to a server. There is no account, no pastebin round trip, and nothing stored.

Frequently asked questions

Is my code or data uploaded anywhere?

No. Everything runs in your browser — JSON, tokens, hashes and encoded text never leave your device, which is why these tools are safe for sensitive snippets.

What does the JWT Decoder show?

It decodes a token's header and payload so you can read the claims it carries — useful when debugging authentication.

Which hash algorithms are supported?

MD5, SHA-1, SHA-256 and SHA-512 — the Hash Generator calculates all four for any text you enter.

Can I format and validate JSON?

Yes. JSON Formatter and Validator formats, minifies and checks JSON, and points out errors clearly when something is wrong.

What is Base64 used for?

Base64 turns binary data or text into plain ASCII, so it can travel safely in URLs, JSON, emails and config files. The encoder here is Unicode-safe, so it handles text in any language.

Do I need an account to use these tools?

No. There is no sign-up and no usage limit — open the tool and use it.
