How to convert SVG to PNG

SVG is a drawing described in words — lines, curves and colours that scale to any size without ever going blurry. PNG is a grid of pixels, fixed forever at the size you export. Converting SVG to PNG is necessary whenever the destination can't draw vectors — social posts, documents, apps — but it is one-way: the PNG can never become a sharp vector again. Here is how to convert at the right size, and what to watch for.

Vector versus raster, in one paragraph

An SVG file is not a picture, it is a set of instructions: draw a circle here, a curve there, fill this shape red. Because it is instructions, it can be drawn at any size — a postage stamp or a billboard — and stay perfectly sharp. A PNG is a grid of coloured squares: it looks perfect at the size it was made, and blurry the moment it is stretched larger. Converting SVG to PNG means following the instructions once, at one chosen size, and freezing the result into pixels.

That is why the export size is the only decision that really matters. Export at the largest size you will ever need — a PNG can always be shrunk cleanly, but it can never be enlarged cleanly. A logo exported at 4000 pixels wide can serve a website, a document and a printout; a logo exported at 400 pixels wide can only ever serve small screens.

What our converter does — and its honest limits

The SVG to PNG Converter rasterizes your SVG at its own size — the width and height written in the file, or its viewBox if no size is given — up to a 4096-pixel cap. Transparency is preserved: a logo on a transparent background stays transparent in the PNG. The conversion runs in your browser, so the file never leaves your device.

One limit is worth knowing before you convert. Browsers refuse to load external resources from a local SVG file — images and fonts the SVG references by web address — for security reasons. So an SVG that depends on an external font will render with a fallback font, and an SVG that embeds a linked image will show a gap where the image should be. Most SVGs are self-contained and convert exactly; if yours depends on outside files, Inkscape below handles them properly.

How to convert SVG to PNG

  1. In your browser — fastest, nothing to install. Use the SVG to PNG Converter: drop the SVG file onto the box and download the PNG. It rasterizes at the SVG's own size, which is right when the file already carries the dimensions you want.
  2. With Inkscape, when you need an exact size. Open the SVG in Inkscape — free, on Windows, Mac and Linux — and choose File, then Export PNG Image. Inkscape lets you set the exact pixel width and height, exports at any resolution, and loads external fonts and images properly. It is the best choice when the PNG must be a specific size, or when the browser conversion looks wrong.
  3. With GIMP, as a third option. Open the SVG in GIMP and it asks what size to render it at — pick the largest size you need — then choose File, then Export As, and save it as a PNG. GIMP is a good option if you plan to edit the rasterized picture afterwards.
  4. Check the PNG at full size. Open the result and zoom to 100%: text and fine lines should be crisp. If text looks like the wrong font, the SVG used an external font the browser could not load — re-export it in Inkscape, which can.

Keep the SVG — always

The PNG is a disposable output; the SVG is the master. Every future size, every edit, every re-export starts from the SVG, and none of them is possible from the PNG. A PNG enlarged later only gets blurry; an SVG re-exported later is perfect at any size. Store the SVG safely and treat PNGs as copies you can regenerate whenever you need them.

The same applies in reverse: never throw away the SVG because the PNG 'looks the same'. It looks the same at one size, on one screen, today. The next use — a bigger screen, a printout, a redesign — will want the vector back, and by then it may be gone.

Questions people ask

Why is my converted PNG blurry?

It was exported too small and then stretched. A PNG cannot be enlarged cleanly — convert the SVG again at a larger size instead. Export at the largest size you will ever need; shrinking a PNG later is always safe, enlarging it never is.

Why does the text in my PNG look like the wrong font?

The SVG references a font by web address, and browsers refuse to load external fonts from a local SVG file for security reasons, so a fallback font is used instead. Re-export the SVG in Inkscape, which loads fonts properly, or convert the text to paths in the SVG first.

Can I convert a PNG back to SVG?

Not really. Tracing tools can guess vector shapes from a PNG's pixels, but the result is an approximation — close for simple logos, poor for photos and detailed art. That is why the original SVG is worth keeping: it is the only true vector version.
