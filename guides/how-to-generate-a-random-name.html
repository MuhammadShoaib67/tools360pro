How to Generate a Random Name

By Muhammad Shoaib · Published 17 November 2026 · Updated 26 November 2026

Sometimes you need a name and it does not matter which one — a character in a story, a test account, a placeholder in a design, a name for a draw. This guide shows how to generate random names quickly, what to do with them, and how to pick the ones that feel right.

Why random names beat invented ones

Invented names repeat the same defaults

Inventing a name on the spot is harder than it looks. The names that come to mind first are usually people you know, characters from things you have read, or the same few defaults — John Smith, Jane Doe — that everyone reaches for. A generator breaks that pattern by pairing first and last names at random, which produces combinations you would never have thought of.

Randomness removes bias

Randomness also removes bias. If you pick names by hand for a test database or a seating plan, you will favour names you like and avoid names you do not. A generator does not play favourites, which is exactly what you want when the names need to be neutral — for testing, for draws, or for examples that should not single anyone out.

What random names are good for

Writers use random names to name characters without getting stuck on the choice — a name that arrives by chance often fits better than one laboured over for an hour. Developers and testers use them to fill databases, forms and screenshots with realistic-looking data that is not anyone's real information. Designers use them in mockups so a layout shows real names instead of lorem ipsum.

Teachers use them for example problems and seating plans, game masters for non-player characters, and anyone running a draw or a secret santa for picking names fairly. In all of these cases the point is the same: a plausible name, instantly, with no personal data involved.

Generate a random name in four steps

  1. Choose a name type. Open the Random Name Generator and pick any for a mix, or male, female or gender-neutral first names.
  2. Choose how many names you want. One for a single character, five or ten for a list, a class, or a batch of test accounts. Decide whether to include a last name.
  3. Click Generate names. A fresh batch appears below. Click Generate again for a new set — with thousands of combinations, repeats are rare.
  4. Copy the ones that fit. Click any name to copy it on its own, or Copy all to copy the whole list at once.

Making the names feel real

A name that fits its context

A random name feels real when it fits its context. A formal document suits a full first and last name; a chat mockup reads better with first names only. If a generated name feels wrong for your character or your test case, generate another batch — with thousands of combinations, the right one is usually a click away.

A match with a real person is coincidence

One thing to keep in mind: any match with a real person is coincidence. These names come from lists of common names, so a generated name will sometimes belong to someone real. That is fine for fiction and testing, but if you publish a name — in a story, a game or a public example — a quick search is worth doing to avoid an unintended clash with a real person.

Other ways to get a random name

Dice and lists are the old method: a list of first names, a list of last names, and a die roll for each. It works, but it is slow for more than a couple of names. Spreadsheets can do it with a random function and two columns of names, which suits bulk generation for test data.

For a handful of names, a browser generator is fastest — no setup, no lists to maintain, and the names appear with one click. For hundreds of names at once, a spreadsheet or a small script is the better tool, because it can produce a whole dataset in one go.

Questions people ask

Are random generated names real people's names?

No. The names are drawn at random from lists of common first and last names. Any match with a real person is coincidence — the generator has no access to any database of real people.

Can I generate only first names?

Yes — uncheck the Include last name box and the generator shows first names only, which suits chat mockups, examples and informal lists.

How many different names can a generator make?

With 80 first names across the three lists and 40 last names, the combinations run into the thousands. Duplicates inside one batch are removed automatically.

Can I use a generated name in a published story?

Yes. The names come from common word lists and anyone can use them. If a name matters to your work, a quick search is still worth doing to avoid clashing with a real person.
