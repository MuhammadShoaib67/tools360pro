How to Scan a QR Code from an Image

QR codes are everywhere — on posters, menus, tickets and screens — but the code you need to read is often already a picture on your device. This guide shows how to scan a QR code from an image file, what to do when a scan fails, and how to check a code safely before opening its link.

Why scan from an image instead of a camera

Phone cameras scan QR codes well — until the code is on the phone itself. A QR code in a screenshot, a downloaded flyer, a photo someone sent you, or a picture on your laptop screen cannot be scanned by pointing your phone at it, because the code is already inside the device. That is the gap an image scanner fills: instead of a camera, it reads the code from a picture file.

Image scanning is also more reliable for awkward codes. A photo can be cropped, straightened and enlarged before scanning, which fixes the angle and distance problems that defeat camera scanning. And it works on any device with a browser — a laptop, a tablet, or a phone — with no app to install.

What a QR code can hold

Most QR codes hold a web link, but the format can store up to about 4,000 characters of text. Restaurants use them for menus, shops for product pages, and events for tickets. Wi-Fi QR codes store a network name and password so a phone can join without typing. Contact QR codes store a name, phone number and email as a digital business card.

That flexibility is why caution matters. A QR code can point anywhere, and you cannot tell where it leads just by looking at it. A scanner that shows you the decoded link before you open it is the safe way to check an unknown code — read the destination first, and only open links that go where you expect.

Scan a QR code from an image in four steps

  1. Get the code into an image file. If the code is on a screen, take a screenshot. If it is on paper, take a photo. If someone sent it to you, save the picture to your device.
  2. Upload the image. Open the QR Code Scanner and choose the image file. The scan starts automatically and runs entirely in your browser — the image is never uploaded.
  3. Read the decoded content. If a QR code is found, its content appears below the preview: a link, some text, a Wi-Fi password, or contact details.
  4. Copy it or open the link. Click Copy text to copy the decoded content, or Open link if the code contains a web address — after checking that the address is the site you expect.

When a scan fails

The most common reason is image quality. A blurry photo, a code photographed at a steep angle, or a code that is partly covered can all defeat the decoder, because it needs to see the three square corner markers and the grid clearly. Very small codes in a large image are another problem — the decoder works best when the code fills a good part of the frame.

If a scan fails, crop the image so the code is large and centred, straighten it if it is tilted, and make sure the lighting is even — glare and shadows break the black-and-white contrast the decoder relies on. QR codes carry error correction, so a damaged code sometimes still works, but a code with a missing corner marker usually cannot be read at all.

Other ways to scan a QR code

On a phone, the camera app is the fastest option for printed codes: point it at the code and a link appears. Google Lens and similar tools can also read codes from photos already on the phone. On a desktop, browser extensions exist, but they need installing and often ask for broad permissions.

For a one-off scan of an image, a browser scanner is the simplest route — no app, no install, no permissions, and the image never leaves your device. That last point matters for codes that might contain private information, like a Wi-Fi password or a personal link.

Questions people ask

Can I scan a QR code without a camera?

Yes. If the code is in a screenshot, a photo or a downloaded image, an image scanner reads it from the file — no camera needed. For a printed code, take a photo of it first, then upload the photo.

Is my image uploaded when I scan it?

No — with a browser scanner, the image is decoded locally on your device and never sent to a server. That matters for codes that might contain private information.

Why does my QR code not scan?

Usually image quality: blur, a steep angle, glare, or a code that is too small in the frame. Crop the image so the code is large and centred, straighten it, and try again.

Is it safe to open a link from a QR code?

Read the decoded link first. Only open it if the address looks like the site you expect — QR codes can point anywhere, and a scanner that shows the destination first is the safe way to check.
