How to resize multiple images at once

By Muhammad Shoaib · Published 17 November 2026 · Updated 17 November 2026

Resizing images one at a time is the kind of repetitive work that eats an afternoon — and the settings drift, so the results come out inconsistent. Here is how to resize multiple images at once, with one setting applied to the whole batch.

Why batch resizing saves more than time

A listing needs a dozen product photos, a blog post needs a set of illustrations, a photo album needs a hundred pictures shrunk for sharing. Done one at a time, each image means opening a file, typing a size, saving, and closing — and the fifteenth image is resized with less care than the first. A batch tool applies one setting to every file, so the whole set comes out uniform.

Uniformity is the point. A product catalogue where every image is 1600 pixels wide looks professional; one where the widths vary looks thrown together. A photo gallery with consistent sizes loads evenly and displays neatly. Batch resizing is not just faster — it is the only practical way to keep a set consistent.

Percentage vs target width

Percentage is the right choice when your images are different sizes and you want them all smaller by the same amount: 50% halves a 4000-pixel photo to 2000 and a 2000-pixel photo to 1000. The set keeps its variety, just smaller — useful for archiving a mixed album.

Target width is the right choice when the destination wants one size: a listing that needs 1600-pixel images, a blog that displays at 800 pixels, a form with a maximum width. Every image comes out at exactly that width, with its height following its own aspect ratio — nothing is ever stretched. If the destination also wants a specific height, resize by width first, then crop the few that need it.

Keeping quality consistent across a batch

A batch often mixes formats — JPGs from a camera, PNGs from a screenshot tool, a WebP from a download. Converting the whole batch to one format is part of the job: JPG makes the smallest files for photos, PNG keeps transparency and loses nothing. The quality setting applies to JPG and WebP output; 85% is a good default that keeps photos looking sharp while cutting the file size substantially.

Check the results before sending them on. A batch that is too aggressive — 10% quality, or a width of 200 — is only visible after the fact, and re-doing a batch costs the time it was meant to save. Resize one image first, check it at full size, then run the batch with the settings that looked right.

How to resize multiple images at once

  1. In your browser — fastest, nothing to install. Use the Bulk Image Resizer: drop all your images in at once, choose a percentage or a target width, and download every resized image together as one ZIP. Nothing is uploaded.
  2. On Windows, with PowerToys. Install Microsoft PowerToys (free, from Microsoft), then select your images in File Explorer, right-click, and choose Resize pictures. Pick a preset or a custom size — PowerToys resizes the whole selection and saves copies alongside the originals.
  3. On a Mac, with Preview. Open all the images in Preview, select them all in the sidebar, then choose Tools, then Adjust Size, and type the new width. The setting applies to every selected image at once. Save each file afterwards — Preview does not save automatically.
  4. On Windows, with IrfanView. IrfanView (free) has a batch conversion tool under File, then Batch Conversion, with resize options and the choice to rename and convert formats at the same time. It is the most powerful of the desktop options, and the most complex.

Naming and organising the results

A batch produces a pile of files, and a pile needs naming. The browser tool names each result after its original plus “-resized”, so the set stays recognisable and never overwrites the originals. Desktop tools vary: PowerToys adds the size to the filename, Preview overwrites unless you save copies first — so duplicate the folder before a Preview batch.

Keep the originals. Resizing down throws pixels away, and the loss cannot be undone — if you later need the large versions, the originals are the only source. Store them in a separate folder, and treat the resized set as the working copy, not the archive.

Questions people ask

How many images can I resize at once?

In the browser, there is no fixed limit, but very large batches use a lot of memory — for hundreds of very large photos, work in batches of 30–50. Desktop tools like IrfanView handle larger batches more comfortably.

Will resizing in bulk stretch my images?

No, if the tool preserves aspect ratio — height follows width automatically. The browser tool always does; in desktop tools, check the “keep aspect ratio” option is on before running the batch.

Does resizing reduce file size too?

Yes — fewer pixels mean a smaller file, especially when you also convert to JPG. Halving the width and height cuts the pixel count to a quarter, and the file size usually falls by a similar amount.
