How to make a QR code for a Facebook page

By Muhammad Shoaib · Published 25 November 2026 · Updated 25 November 2026

A QR code turns a printed surface into a doorway to your Facebook Page: someone points a phone at your shop window, menu or business card and lands straight on your Page, with nothing to type and no name to search for. Making one takes under a minute, costs nothing and needs no account — but two details decide whether it works: the link inside the code has to be the right one, and the printed code has to be big and clear enough to scan. Here is how to make a QR code for a Facebook Page, and the mistakes that leave codes unscanned.

First, get the right link

A QR code is only as good as the address inside it, so sort the link out before you make the code. Open your Page in a browser and look at the address bar: it should read facebook.com/YourPageName. That short address comes from the Page's username, and it makes a cleaner code than a long address full of numbers — the shorter the address, the simpler the pattern, and the easier it scans at small sizes.

If your Page has no username yet, claim one first in the Page's settings, then make the code. It matters because the codes made here are static: the address is encoded directly into the pattern, so if you change the username later, the old code points at an address that no longer exists and every printed copy stops working at once. Get the username right first, then print.

And copy the link from the Page itself, never from a post on the Page. Post links change and expire; the Page link does not. On a phone, open the Page in a browser rather than the app — the app hides the address — or use the Page menu's copy-link option and check that what you copied is the Page address, not a post.

Make the code in under a minute

  1. Open our free QR Code Generator — no account, no sign-up, and the code never expires.
  2. Paste your Page link into the box. The code updates live as you type.
  3. Check the preview, then test it. Point your phone camera at the preview and confirm it opens your Page — not someone else's, and not an error page. That five-second test catches a mistyped address before it becomes a hundred misprinted posters.
  4. Download it — PNG for screens, SVG for anything printed. SVG stays perfectly sharp at any size, which is what print needs. For a PNG that will be printed, pick the largest download size, 1024 pixels.

Do not go hunting inside Facebook for a built-in QR button. Facebook's own Page QR option has been removed, so the generator route is the one that keeps working — and it gives you a proper print file, which the in-app option never did.

Print it so it actually scans

A QR code only works if someone can scan it comfortably, and that is a question of size and distance. The further away the scanner stands, the larger the code must be. A code on a business card is scanned from a few centimetres away, so it can be small — around 2 cm across is enough. A code on a poster across a room needs to be much larger, and a code on a shop window that people read from the pavement needs to be larger still. A rough rule that holds up in practice: the code should be at least one tenth of the distance people will scan it from. If they stand a metre away, make it at least 10 cm across.

Most unscannable codes fail on one of four things, and all four are easy to avoid. First, low contrast: light squares on a dark background, brand colours too close together, or a code printed over a photograph. Dark squares on a light background are the safe choice every time. Second, no quiet zone: cameras need a plain border around the code to find its edges, so leave breathing room and never crowd the code against other graphics or trim it tight. Third, printing too small or at too low a resolution. A PNG stretched far beyond its pixel size turns fuzzy, and fuzzy squares do not scan — which is why SVG is the right download for print. Fourth, and most expensive, never testing the printed copy. Paper, light and distance change what a camera sees, so scan the actual printed piece with a phone — not just the preview on your screen — before you print a large batch. One test scan of the finished print catches all four mistakes at once.

Where to put it

Good places for a Page code are the ones where the person is already looking at your business and has a phone in their hand: the shop window, the menu or table, the business card, the back of a receipt, product packaging, a flyer, a poster, and the footer of a printed invoice. Wherever you put it, add a short line next to it saying what it opens — "Scan to follow us on Facebook" tells people why they should bother, and it costs nothing. Less good are places where nobody pauses — a passing vehicle, a tiny corner of a crowded poster — because a code nobody has time to scan is decoration, not a doorway.

One more place worth using: the bottom of your printed invoice or receipt, next to the thank-you line. A customer who has just paid is the most likely person to follow the Page, and a code there turns a finished sale into a follower without a word from anyone. What scanning does — and does not do

Scanning the code opens your Page — in the Facebook app if the person has it installed, in the browser if they do not. It does not follow the Page for them, and it does not like it either: the person still taps Follow or Like themselves. That is worth knowing before you promise anyone "scan to follow" — the code gets them to the Page, and the Page itself has to earn the follow.

Two honest limits. First, if your Page is unpublished, or restricted by age or country, a visitor without a Facebook account — or outside the allowed group — may hit a login wall instead of your Page. A code can only open what the Page allows the public to see, so check the Page opens for a logged-out visitor before you print it. Second, the code is static and permanent: it never expires, needs no account and cannot be switched off — but it also cannot be edited. If the Page address changes, make a new code and reprint. For a Page address that is not going to change, that permanence is exactly the point.

Questions people ask

Is there a free QR code for a Facebook Page?

Yes. Copy your Page link, paste it into our free QR Code Generator and download the code — no account, no sign-up and no expiry. Facebook's own built-in Page QR option has been removed, so a generator pointed at your Page URL is the reliable route, and it gives you a proper PNG or SVG file for print.

Do I need a Facebook account to scan the code?

No — anyone with a phone camera can scan it, and the Page opens in the Facebook app or the browser. But if the Page is unpublished or restricted by age or country, a visitor who is logged out may be asked to log in first, so check the Page opens for a logged-out visitor before you print the code.

Will the QR code expire?

No. The code is static, which means your Page address is encoded directly into the pattern — there is no redirect service in between, so nothing can switch it off and it never expires. The only thing that breaks it is changing the Page address itself, for example by changing the Page username, so set the username first and print after.

PNG or SVG — which should I download?

Use SVG for anything printed — shop windows, posters, packaging and business cards — because it stays perfectly sharp at any size. Use PNG for screens, documents and social posts, and pick the largest size, 1024 pixels, if a PNG is going to print. Whichever you choose, test the printed code with a phone before printing a large batch.
