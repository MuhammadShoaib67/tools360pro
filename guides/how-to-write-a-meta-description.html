How to Write a Meta Description That Gets Clicked

The meta description is the short paragraph under your title in Google's search results. Google has said it is not a ranking factor — but it is your best free advertising copy, and a good description is often the reason a searcher clicks your result instead of the one above it. This guide shows you how to write descriptions that earn the click.

What a meta description does (and does not do)

Google has confirmed that the meta description is not a ranking factor. Writing one will not move your page up the results. What it does is win clicks: when your page appears in the results, the description is the pitch that convinces a searcher to choose you over the listing above or below. A higher click-through rate means more traffic from the same ranking, which is a real result.

One honest caveat: Google rewrites descriptions often, pulling a snippet from your page content when it thinks that text matches the search query better. A well-written description still gets used often, especially for branded and exact-match searches — and a missing description guarantees Google writes one for you, usually badly.

The anatomy of a description that gets clicked

Start with the keyword. Google bolds words in the description that match the search query, and bold text draws the eye — a description containing the searcher's words stands out in a page of results. Follow it with a specific benefit or a direct answer, and finish with a call to action: learn how, try it free, see the steps. Numbers and specifics beat vague claims every time — 12 templates beats many templates, in 2 minutes beats quickly.

And match the page. A description that promises what the page does not deliver earns a click and an immediate bounce, which helps nobody. The best descriptions are accurate summaries with a reason to click, not adverts for a different page.

Write a meta description in five steps

  1. Know the page's keyword and promise. What the page delivers, in one sentence. If you cannot state it in one sentence, the page itself may need work before the description does.
  2. Draft two or three options. Try a benefit-led version, a question-led version, and a number-led version. The Meta Description Generator builds template options from your keyword so you can compare them instead of writing from a blank page.
  3. Hit 150 to 160 characters. Shorter is fine for a simple page; longer gets cut off with an ellipsis. Put the key point in the first 120 characters, because mobile search shows even less of the description than desktop does.
  4. Preview it as a searcher sees it. Check the title, URL and description together in a SERP preview. A description that reads well on its own can clash with the title — if both say the same thing, rewrite one of them to add new information.
  5. Add it and check the result. The description lives in a <meta name="description"> tag in the head of the page, or in the meta description field of your WordPress SEO plugin. After Google recrawls the page, check what it actually shows — and expect a rewrite on some queries.

Meta description mistakes

Leaving it blank is the most common mistake, and the easiest to fix. Stuffing the keyword in three times reads like spam and wastes space that could sell the click. Duplicating the same description across the whole site is a missed opportunity on every page. Writing 300 characters means most of it is truncated and never seen.

Two more to avoid: promising what the page does not deliver, and using straight double quotes inside the description text — they can break the HTML attribute if they are not escaped, which can hide the whole tag from Google.

Descriptions for different page types

A product page description leads with the key feature, hints at price or availability, and ends with a call to action. A blog post description states the answer or the hook — the one thing the reader will learn. A category page description says what the category contains and adds a differentiator. A homepage description says what you do and for whom, in plain language. One formula does not fit all four.

Questions people ask

How long should a meta description be?

Aim for 150 to 160 characters on desktop. Google truncates longer descriptions, and mobile shows even less, so put the most important point first.

Does the meta description affect rankings?

No. Google has confirmed the meta description is not a ranking factor. Its job is to win clicks, and a higher click-through rate is still valuable traffic.

Why does Google show a different description?

Google often writes its own snippet from your page content when it thinks that text matches the search query better. A well-written description still gets used often, especially for branded and exact-match searches.

Should every page have a unique meta description?

Yes. Duplicate descriptions across pages are a missed opportunity and can look sloppy in search results. Each page deserves its own one or two sentences.
