How to create a strong password you can actually remember

By Muhammad Shoaib · Published 20 November 2026 · Updated 20 November 2026

Everyone knows the advice: make it long, make it random, never reuse it. The problem is that a random string like k9#mQ2!zX is impossible to remember, so people do the worst thing instead — they reuse one weak password everywhere. There is a better answer: a passphrase. Here is how to create a strong password you can actually remember, and when to use a random one instead.

Why strong passwords are hard to remember

The advice is not wrong, it is just aimed at the wrong thing. Security guidance treats the password as a secret only a computer must guess, but a password is also something a human must recall — sometimes typed on a phone keyboard, sometimes read over the phone, sometimes entered on a laptop with no password manager installed. A sixteen-character tangle of symbols is strong on paper and useless in practice if you cannot remember it, because the moment you forget it you reset it, write it on a sticky note, or quietly go back to the old familiar one.

That is how reuse happens. Studies of leaked password lists keep finding the same pattern: people do not have one weak password, they have one password, used everywhere. The strength of that single password barely matters — once one site leaks it, every account falls with it. The real problem was never that the password was too short. It was that remembering a different strong password for every account felt impossible, so nobody tried.

The passphrase trick: words instead of characters

A passphrase is a password made of words instead of random characters — something like River-Tiger-Cloud-Maple7. It looks friendlier, and it is: four ordinary words are far easier to hold in your head than sixteen random symbols, and far easier to type correctly on a first attempt. The surprise is that it is not weaker. Password strength is not about how strange the password looks; it is about how many possibilities an attacker must try, and four words picked at random from a large list create more possibilities than most random strings people actually use.

The word random is doing all the work here. Words from a song lyric, a favourite quote, or a sentence you invented ("Ilovemydog2024") are predictable — attackers try those first. Words picked blindly by a generator, with no connection to each other, are not. River, Tiger, Cloud and Maple have nothing to do with one another, and that is exactly the point: there is no pattern to guess, only a very large number of combinations to try. How to build a passphrase you will remember

  1. Start with four random words. Four is the minimum; five or six is better for anything important, like your email or your password manager itself. Each extra word multiplies the guessing effort enormously while adding almost nothing to the effort of remembering.
  2. Join them with a separator you can type easily. A hyphen is the simplest — River-Tiger-Cloud-Maple — but a dot or an underscore works too. Pick one and use it the same way every time.
  3. Capitalise the first letter of each word. It costs nothing to remember, it adds guessing resistance, and it makes the passphrase easier to read at a glance.
  4. Add a number at the end. A single digit, or a short number that means nothing to anyone else, satisfies sites that demand a digit without making the passphrase harder to recall.
  5. Picture it once, then use it. Say the four words out loud and imagine them together — a river, a tiger, a cloud, a maple tree. A small mental picture is worth more than repeating the password ten times. Then type it a few times over the next day; after that, it sticks.

Test your result honestly: if you can type it from memory tomorrow morning without looking, it is memorable enough. If you cannot, generate a fresh set of words rather than forcing the first set — a passphrase you have to look up every time is a password you will eventually replace with something weaker. When a random password is the better choice

Passphrases are for passwords that must live in your head: a laptop login, a Wi-Fi password shared with guests, the master password of your password manager, a code you read over the phone. For everything else, a random password is better — and that is most of your accounts. If a password manager fills it in for you, you never need to remember it or type it, so there is no reason to make it memorable at all. A sixteen-character random string with mixed letters, numbers and symbols is the right tool for an account you will only ever open through the manager.

The honest rule is therefore twofold: use a passphrase for the handful of passwords you must know, and use a random password for the dozens you only need the manager to know. The passphrase protects the manager, and the manager protects everything else. Trying to memorise a random string for every account is a plan that fails quietly; trying to use a passphrase everywhere wastes the one advantage a manager gives you, which is never having to remember at all.

The rules that matter more than cleverness

No password trick survives bad habits, and the habits that matter are few and plain. First, one password per account, always — reuse is the single most common way strong passwords fail, because a leak at a forgotten forum hands attackers the key to your email. Second, store every password in a reputable password manager the moment you create it, and let the manager fill it in; a password you have to remember is a password you will eventually simplify.

Third, turn on two-factor authentication wherever it is offered, especially on email — your email account guards the password resets for everything else, so it deserves the strongest passphrase you own and a second factor on top. Fourth, length beats cleverness: a twenty-character password of plain letters is stronger than an eight-character tangle of symbols, because each extra character multiplies the guessing effort far more than swapping a letter for a symbol ever could. And finally, when a site caps password length, use the maximum it allows — the cap is the site's limit, not a recommendation.

What not to do

  • Do not use words anyone could guess about you — pet names, birthdays, your team, your street. Attackers try those first, and your social media hands them the list.
  • Do not build a passphrase from a sentence or a quote. "To be or not to be" is a famous line, not a secret; its strength is an illusion.
  • Do not reuse a passphrase you like. A passphrase you reuse is no safer than a password you reuse — one leak opens every account that shares it.
  • Do not write passwords on paper stuck to the monitor — or in an unprotected note on your phone. A password manager is the place for them; the one thing you memorise is the manager's own passphrase.
  • Do not "strengthen" a weak password with a predictable swap — replacing a with @ or o with 0 fools nobody, because attackers try those substitutions first. Length and randomness are what count.

Questions people ask

How many words should a passphrase have?

At least four random words, and five or six is better for anything important. Each extra word multiplies the guessing effort enormously, while adding almost nothing to the effort of remembering — four words are barely harder to recall than three, but far harder to guess. Never use fewer than four.

Is a passphrase as strong as a random password?

Yes, when the words are random. A passphrase of four or more random words carries as much guessing resistance as a long random string of characters, because the strength comes from how many possibilities an attacker must try, not from how strange the password looks. The catch is the word random: words taken from a song, a quote or a sentence you made up are predictable, and predictable is weak.

Should I use the same strong password everywhere?

No — reuse cancels the strength. If one site leaks its passwords, every account sharing that password is open, no matter how strong it was. Generate a unique password for every account and store them in a password manager; the one password you must remember is the manager's own, and that is the one to make a passphrase.

What if a site does not allow long passwords?

Use the maximum length the site allows, and make every character count: mix uppercase and lowercase, numbers and symbols, and never reuse a password from another site. If a site rejects spaces or symbols in a passphrase, switch the separator to a hyphen or remove it — the words themselves carry most of the strength, and a short limit is the site's weakness, not yours.
