How to check image dimensions

Before you print, upload or submit an image, you need one fact: how big is it, in pixels? Here is how to check image dimensions in seconds — what the numbers mean, and where to find them on any device.

Dimensions, megapixels and file size

Dimensions are the image's size in pixels — width first, then height. A photo of 4000 × 3000 has 4000 pixels across and 3000 down. Megapixels are the total: width times height, divided by a million. That photo is 12 megapixels. More megapixels mean more detail, and also a bigger file.

File size is a different number: how much storage the file takes, in kilobytes or megabytes. Two images with identical dimensions can differ tenfold in file size — a detailed photo compresses poorly, a simple graphic compresses to almost nothing, and PNG files are several times larger than JPGs of the same picture. Dimensions tell you whether the image is big enough for the job; file size tells you whether it will upload quickly.

Why dimensions matter before you upload or print

Dimensions are a hard limit. An image can be shrunk to any smaller size without losing visible quality, but enlarging it beyond its pixel dimensions only spreads the existing pixels thinner — it never adds detail. A 800-pixel image printed at 8 inches wide gives 100 pixels per inch: visibly soft. The same image on a phone screen looks fine, because the screen is small.

Forms and uploaders often reject images outside their limits, and their error messages rarely explain why. Checking first saves the guessing: if a form wants at least 1000 pixels and your image is 800 wide, you know the problem before uploading. If a print shop wants 300 dpi, multiply the print size in inches by 300 — a 4 × 6 print needs 1200 × 1800 pixels.

Finding dimensions without any tool

Every operating system shows dimensions somewhere, though none of them makes it obvious. On Windows, right-click the file, choose Properties, then Details — the dimensions are listed there. On a Mac, right-click and choose Get Info, or open the image in Preview and choose Tools, then Show Inspector. On an iPhone, open the photo, swipe up, and the details panel shows the dimensions; on Android, open the photo in Gallery and tap the details or info icon.

Those routes work, but they take several clicks and show one file at a time. A browser checker shows dimensions, megapixels, aspect ratio and file size together, for any file, with no clicks through menus — which is why it is the faster route when you have more than one image to check.

How to check image dimensions

  1. In your browser — fastest, most detail. Use the Image Dimension Checker: drop the image in and see its width, height, megapixels, aspect ratio, orientation and file size instantly. Nothing is uploaded.
  2. On Windows. Right-click the image file, choose Properties, then the Details tab — the dimensions are listed under Image. Or open the image in the Photos app and look for the file information panel.
  3. On a Mac. Right-click the file and choose Get Info — the dimensions appear under More Info. Or open it in Preview, choose Tools, then Show Inspector, for dimensions plus file size and format.
  4. On your phone. On iPhone, open the photo in the Photos app and swipe up — the details panel shows dimensions. On Android, open the photo in Gallery and tap the three-dot menu, then Details.

What to do with the numbers

If the image is big enough but the file is too heavy, compress it — the Compress Image tool shrinks the file without changing the dimensions. If the dimensions are too small for the job, no compression trick will help: you need a larger original, or an upscaler. The AI Image Upscaler reconstructs detail for small images instead of merely stretching pixels.

If the shape is wrong — a landscape photo for a square post, a tall image for a wide banner — the dimensions tell you how much must be cropped or padded. The Crop Image tool and the Square Image Maker fix the shape without guessing.

Questions people ask

What is the difference between dimensions and file size?

Dimensions are the image's size in pixels (width × height). File size is how much storage the file takes (KB or MB). Two images with the same dimensions can have very different file sizes, depending on detail and format.

How many megapixels do I need for printing?

For a sharp print at 300 dpi, you need 300 pixels per inch of printed size — 1200 × 1800 for a 4 × 6 inch print (2.2 MP), 2400 × 3000 for 8 × 10 (7.2 MP). Fewer pixels still print, just softer.

Why does my phone photo show a different size than expected?

Phones often save photos larger than the screen shows, and some save a smaller preview alongside the full image. A checker measures the actual file you give it, so the numbers are the file's real dimensions.
