How to make a QR code for a link, a PDF or a Google Form

A QR code is the fastest way to send someone to a link, a PDF or a Google Form: no typing, no spelling mistakes, no lost URL. Point a phone camera at it and the destination opens. Here is how to make one that scans every time — and the mistakes that make codes unreadable.

What a QR code actually stores

A QR code is just text drawn as a pattern of black and white squares. When you make a code for a link, the link itself is written into the pattern — the phone reads the squares, finds the address, and opens it. Nothing is stored on a server, and nothing expires, because there is nothing to expire: the code is a picture of your link.

That is the honest difference between the two kinds of QR code you will meet online. A static code stores the destination directly, works forever, and cannot track who scanned it — that is what our QR Code Generator makes. A dynamic code stores a short redirect link owned by a service, so the destination can be changed later and scans can be counted — but it stops working if you stop paying for that service. For a menu, a poster, a business card or an invoice, static is the right choice: it never breaks, and nobody is watching your scans.

Make a QR code for a link

  1. Copy the exact link. Open the page you want people to reach and copy its address from the browser bar — including the https:// at the start. A link typed from memory is where most broken codes begin.
  2. Paste it into the generator. Open the QR Code Generator and paste the link. The code appears instantly as you type, and it is generated entirely in your browser — the link is never uploaded anywhere.
  3. Test it before you share it. Scan the code with your own phone camera. It should open exactly the page you intended, not a search result and not an error page.
  4. Download it. Use PNG for websites, documents and social posts. Use SVG for print, posters and signage, because it stays perfectly sharp at any size.

One habit saves more trouble than any other: shorten long links before you encode them. A short link makes a simpler pattern with bigger squares, and bigger squares scan faster and from further away. A link with tracking parameters and session IDs makes a dense, fiddly code that struggles in poor light.

Make a QR code for a PDF

A QR code cannot hold a whole PDF file — but it does not need to. It only needs the link to the PDF. Upload the file somewhere with a public link first: Google Drive, Dropbox, your own website, or any file host. Then copy that link and make a code from it exactly as above. Whoever scans it opens the PDF in their browser.

The one step people forget is the sharing setting. If the PDF is set to "only people I share with", scanners hit a sign-in wall instead of the document — and you will never know, because the code itself scans perfectly. Before you print anything, open the link in a private browser window (or a browser where you are signed out) and confirm the PDF actually opens. A menu, a price list, a portfolio or a catalogue all work this way, and the code never expires as long as the file stays at the same link.

Make a QR code for a Google Form

Google Forms are one of the most common QR code jobs — event registrations, feedback forms, order forms, class surveys — because a form on a poster is useless if nobody can type its address. In Google Forms, click Send, then the link icon, and copy the short link it offers. Paste that link into the QR Code Generator, download the code, and place it on the poster, the table card or the slide where people will see it.

Two details matter here. First, use the short link Google offers rather than the long edit URL — the edit URL opens the form for editing, which is the last thing you want strangers to reach. Second, test the code as a stranger would: scan it, fill in the form once, and check the response actually arrives in your form. A form QR code on an event poster is usually scanned in a crowd, in poor light, from a metre away — so print it large (at least 3–4 cm across) and keep the area around it clear.

Make a QR code for a website or a Facebook page

The method is the same for any destination: a website homepage, a Facebook page, an Instagram profile, a YouTube video. Copy the page's link, paste it into the generator, test it, download it. For a Facebook page, copy the link from the page itself rather than from a post — post links change, page links do not. And put the code where people can actually use it: a shop window, a receipt, a business card, the bottom of an invoice. A QR code on an invoice that opens your payment page turns "I will pay later" into a payment made on the spot — which is why our guide to your first invoice recommends adding one. Print it so it scans: size, contrast and the quiet zone

Most QR codes that fail were made correctly and printed badly. Three rules prevent nearly every failure. Contrast first: dark modules on a light background scan most reliably — light-on-dark, coloured modules on a coloured background, and codes printed over photographs all fail more often than plain black on white. Size second: a code for a short link should be at least 2 cm across on paper; longer links make denser codes, so print them larger. A business card code should be small but never tiny — if you have to hold the phone close and steady, it is too small. Quiet zone third: leave a clear white margin around the code, about four squares wide, with nothing inside it — no text, no logo, no border. Scanners use that empty border to find the code, and crowding it is the single most common print mistake.

One last check before you print a hundred copies: scan the finished file — the actual PDF or image you are about to send to the printer — with two different phones, one iPhone and one Android if you can. If either struggles, enlarge the code or shorten the link. Fixing it now costs a minute; fixing it after printing costs the whole batch.

A note on safety

QR codes are convenient precisely because nobody can read them at a glance — and that is also their risk. A code on a poster, a parking meter or a restaurant table can point anywhere, including a fake login page. So scan with the same caution you would use before clicking a link in an email: check the address your phone shows before you tap "open", and be suspicious of any code that leads to a sign-in page or a payment you did not expect. The same rule applies in reverse when you publish a code: only encode destinations you control, and never reprint a code someone else handed you without checking where it leads. Questions people ask

Do QR codes made here expire?

No. The QR codes from our generator are static: the link or text is written directly into the code itself, so the code keeps working for as long as the destination link works. There is no redirect, no tracking and no subscription in between — a code printed on a poster five years ago still scans today, as long as the page it points to is still online.

Can a QR code link straight to a PDF file?

Yes, if the PDF is hosted somewhere with a public link — Google Drive, Dropbox, your website, or any file host. Copy the link to the PDF and make a QR code from it, exactly as you would for a website. The person who scans it opens the PDF in their browser. Just make sure the sharing setting on the file is actually public, or scanners will hit a sign-in wall instead of the document.

Why will my QR code not scan?

The usual causes are low contrast, a code printed too small, or a code so dense with text that phone cameras cannot resolve it. Use dark modules on a light background, print at least 2 cm across for a short link (larger for long ones), leave a clear white margin around the code, and always test it with a real phone before you print a hundred copies.
