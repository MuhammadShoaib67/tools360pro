How to Convert Text to Morse Code

Converting text to Morse code is a one-click job: type your message, and every letter becomes its pattern of dots and dashes. You can also listen to the result as beeps, and decode Morse code back to text the same way. No sign-up, no app to install.

How Morse code works

Morse code represents each letter and number as a pattern of short and long signals — dots and dashes. The most common letters get the shortest codes: E is a single dot, T is a single dash, while rare letters like Q and Z get longer patterns. That design is deliberate, from a time when every signal cost time and effort, and it is why Morse is so efficient to send by hand.

Timing is part of the code. A dash lasts three times as long as a dot, the gap between parts of one letter is one dot long, the gap between letters is three dots, and the gap between words is seven dots. A good translator follows those rules when it plays audio, so what you hear is real Morse timing, not just a string of beeps.

A code that refused to die

Samuel Morse and Alfred Vail developed the code in the 1830s and 1840s for the electric telegraph, and for over a century it carried the world's long-distance messages — news, shipping, railways and war. The distress signal SOS, three dots, three dashes, three dots, became the most famous pattern in the world, chosen because it is unmistakable even through heavy interference.

Morse faded from commercial use as voice radio and then the internet took over, and the last commercial Morse stations closed in the late 1990s. But it never disappeared: radio amateurs still use it, it is still taught in some military and scouting programmes, and it remains the simplest way to send a message with nothing but a light, a buzzer or a tapped pipe.

Convert text to Morse code in four steps

  1. Type your message. Write the text you want to convert — a name, a word, a short sentence. Keep it simple to start with: SOS is the classic first message.
  2. Open the translator. Go to the Morse Code Translator. It runs entirely in your browser, so nothing you type is uploaded anywhere.
  3. Click Text to Morse. Every letter becomes its dot-and-dash pattern. Letters are separated by spaces and words by a slash, so the code stays readable.
  4. Listen or copy. Press Play Morse to hear the message as beeps with real Morse timing, or Copy output to share the written code.

Decoding Morse code back to text

Going the other way works the same way: paste Morse code — dots and dashes separated by spaces, words separated by slashes — and click Morse to Text. The translator looks up each pattern and returns the letters. Patterns it does not recognise are skipped, with a note saying how many were skipped, so a mistyped pattern does not silently corrupt the message.

If your Morse code has no slashes between words, the decoder reads the whole message as one long word, because it has no way to know where one word ends and the next begins. Add a slash between words when you write Morse by hand, and the decoding comes out clean.

Learning the code

The best way to learn Morse is by sound, not by memorising dot-and-dash charts. Start with the most common letters — E, T, A, O, I, N — and practise recognising their rhythms rather than counting dots. Short daily sessions beat long cramming, and sending your own name or short words makes the patterns stick faster than drilling random letters.

A translator helps in two ways: convert a word to see its code, then press Play to hear how it sounds. Listening while reading the pattern connects the sound to the letter, which is exactly how operators learned it. After a few days of short practice, SOS and your own name usually feel automatic.

Questions people ask

What is SOS in Morse code?

Three dots, three dashes, three dots: ... --- ... It is the international distress signal, chosen because the pattern is simple and unmistakable.

How are words separated in Morse code?

With a slash in written Morse, and with a gap of seven dot-lengths in sound. This tool writes a slash between words and plays the full gap when you press Play.

Why were some of my characters skipped?

Only letters, numbers and common punctuation have Morse codes. Characters outside that set, like emoji or letters with accents, have no standard code and are skipped with a note.

Can I decode Morse code written with spaces only?

Yes, if letters are separated by spaces. Words need a slash between them, or the decoder will read the whole message as one long word.
