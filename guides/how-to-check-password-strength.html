How to Check Password Strength

A password is only as strong as its weakest point, and the only way to know is to check it. This guide explains how strength is measured, what a crack-time estimate really means, and which fixes raise a weak password to a strong one — with a free checker you can use in your browser.

What password strength actually measures

Password strength is a measure of how long it would take an attacker to guess your password. Three things decide it: length, character variety, and predictability. Length matters most — every extra character multiplies the number of combinations an attacker must try, so a 16-character password is enormously harder to crack than an 8-character one.

Character variety is the second factor. A password drawn from lowercase letters alone has 26 possibilities per character; adding uppercase letters, digits and symbols widens the set to 95, and each extra character then multiplies the search space by 95 instead of 26. Predictability is the third factor, and it works against you: common passwords, dictionary words and obvious patterns are tried first, so they fall fast no matter how they look.

Why length beats complexity

Security advice used to focus on complexity — mix symbols, avoid patterns, change your password every month. The research has moved on: length is now the single most important factor, because it grows the search space exponentially while complexity only grows it linearly. A passphrase of four random words is both longer and easier to remember than an 8-character jumble of symbols.

That does not mean complexity is worthless — a long password with mixed characters is stronger than a long password of one type. But if you can only fix one thing, make the password longer. Going from 8 to 12 characters is a bigger jump in strength than adding a symbol to an 8-character password, and going to 16 is bigger still.

Check a password in four steps

  1. Type the password into a checker. Open the Password Strength Checker and type the password you want to test. The check runs in your browser — nothing is sent or stored anywhere.
  2. Read the score and the label. The checker gives a score out of 100 and a label from Very weak to Very strong. Aim for Strong (60 or higher) for everyday accounts and Very strong (80 or higher) for email and banking.
  3. Read the feedback list. It names the exact weaknesses found: short length, a common pattern, only one kind of character, or a password that appears on lists of the most common passwords.
  4. Fix the weaknesses one at a time. Add length first, then mix in more character types. Watch the score and the crack-time estimate rise as you fix each problem.

What the crack-time estimate means

A crack-time estimate is calculated from the password's length and character set, assuming an attacker trying billions of guesses per second — the speed of a fast offline attack against a stolen password database. It answers the question: if someone got the scrambled version of your password, how long would guessing take?

Treat the number as a rough guide, not a promise. A password that appears in a leaked list can be cracked instantly no matter how long it is, because attackers try known passwords before they try random ones. And a strong password reused across sites is only as safe as the weakest site that stores it. Length and variety protect against guessing; uniqueness protects against leaks.

Other ways to check a password

Password managers such as Bitwarden, 1Password and the built-in managers in Chrome and Edge include strength checks and breach alerts: they flag weak passwords and tell you if a password has appeared in a known data breach. Those checks are convenient because they run on passwords you already use.

For a one-off check of a single password, a browser checker is faster — no account, no install, no password vault to set up. Whatever method you use, the advice is the same: long, mixed, unique, and paired with two-factor authentication on the accounts that matter.

Questions people ask

What is a good password strength score?

Aim for Strong (60 or higher) for everyday accounts and Very strong (80 or higher) for email, banking and anything that can reset other passwords. Length matters most — 12 characters or more with mixed character types.

How long should a password be?

At least 12 characters for important accounts, and 16 or more is better. Every extra character multiplies the combinations an attacker must try, so length is the biggest single factor in strength.

Is a passphrase better than a random password?

A passphrase of four random words is long and memorable, which makes it a good choice for passwords you must type. A fully random password from a password manager is stronger, but only if you do not need to remember it.

Does changing my password regularly help?

Only if the password was weak or leaked. Regular forced changes push people toward weaker, predictable passwords. Change a password when it is weak, reused, or involved in a breach — not on a schedule.
