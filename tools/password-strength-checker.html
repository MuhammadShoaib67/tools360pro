How password strength is measured

This checker scores a password on three things: length, character variety, and patterns. Length earns the most points — a password of 16 characters starts far ahead of one with 8, because every extra character multiplies the number of combinations an attacker must try. Character variety adds points for each set used: lowercase letters, uppercase letters, digits and symbols. A password that mixes all four is harder to guess than one drawn from a single set.

Patterns lose points. Passwords on public lists of the most common passwords — password, 123456, qwerty — are penalised heavily, because attackers try those first and crack them instantly. Predictable sequences like 123 or abc, and runs of the same character like aaa, are penalised too. The final score is a simple 0 to 100 scale, grouped into five labels from Very weak to Very strong. It is an estimate of resistance to guessing, not a guarantee — a password can score well and still be unsafe if it has been leaked before.

What makes a password weak

The weakest passwords are short and predictable. Anything under 8 characters can be brute-forced quickly by modern hardware, and anything that appears on a common-password list is effectively no password at all — it is the first thing an attacker tries. Dictionary words on their own are weak for the same reason: guessing tools run through word lists before they try random combinations.

Personal details are weak too, even when they look random. A pet's name, a birthday, a favourite team or a hometown are all guessable by someone who knows a little about you — and much of that information is public on social media. Reusing a password across sites is a different kind of weakness: it does not matter how strong the password is if one site leaks it and the same password opens your email, your bank and your social accounts.

How to make a strong password you can remember

The best method is a passphrase: three or four random words strung together, like correct horse battery staple. It is long, which is what matters most, and it is far easier to remember than a short jumble of symbols. Add a number and a symbol if the site requires them, and avoid words that describe you or your life.

For accounts that matter, a password manager is the better answer — it generates and stores a long random password for every site, so you only have to remember one. Pair it with two-factor authentication where it is offered, and the strength of any single password stops being a single point of failure. Frequently asked questions

Is my password uploaded or stored anywhere?

No. The check runs entirely in your browser with JavaScript. Your password never leaves this page, is never sent to a server, and is not stored in any way.

What is a good password score?

Aim for Strong (60 or higher) for everyday accounts and Very strong (80 or higher) for email, banking and anything that can reset other passwords. Length matters most — 12 characters or more with mixed character types.

How is the crack time estimated?

It is calculated from the password length and the size of the character set it uses, assuming an attacker trying 10 billion guesses per second. It is a rough estimate: a password that appears in a leaked list can be cracked instantly regardless of length.

Is a long password with only letters strong?

Length helps a lot, and a long passphrase of random words can be strong. But mixing in digits and symbols widens the character set and raises the score further. The strongest passwords are both long and mixed.

Should I change a password that scores Fair?

If it protects anything important, yes — make it longer and add character variety. For low-value accounts, Fair is acceptable, but never reuse the same password across sites.
