How to use the Edit PDF tool

  1. Drop the PDF onto the box, or click to choose it — it opens here in your browser, never on a server.
  2. Type the text you want to add, pick its size and colour, then click on the page where it should go. Drag the placed text to move it, or remove it from the list below the page.
  3. Use the buttons to rotate the current page 90 degrees or delete it. The page overview shows every page and its state — a deleted page can be restored the same way.
  4. Press Download edited PDF — your edited file is built on the spot and downloaded.

Adding a note to a form, dating a scanned letter, labelling a diagram or correcting a cover page are all one-minute jobs here: type, click, download. The original pages are never re-rendered, so the text and images that were already in the file stay sharp, and the pages you did not touch stay exactly as they were.

What you can and cannot change in a PDF

A PDF is a finished document, not a Word file — the words inside it are placed on the page, not stored as editable text. That is why no browser tool can rewrite a sentence that is already in a PDF: this tool adds new text on top of a page, so you can label, date, annotate and correct by addition, but the original words stay underneath. If a paragraph itself is wrong, the fix belongs in the document it came from — the Word file, the invoice system, the form builder — and a fresh PDF afterwards.

What this tool does change is real and useful: new text in a size and colour you choose, placed exactly where you click; pages removed entirely, so a draft page or a blank scan never reaches the reader; and pages turned 90 degrees, so a sideways scan reads upright. Rotation and deletion happen without re-rendering anything, so quality is untouched. And because everything runs in your browser, a personal document — a contract, a medical form, an ID scan — is never uploaded anywhere.

Frequently asked questions

Can I change the text that is already in my PDF?

No. This tool adds new text on top of a page — it cannot edit, erase or reword the text that is already in the PDF. To change existing wording you need the original document (for example the Word file it came from) or a full PDF editor. What this tool does well is add labels, dates, corrections and notes, delete pages and rotate pages.

Is my PDF uploaded to a server?

No. The PDF is opened, edited and saved entirely in your browser — the file never leaves your device, which is why this tool is safe for personal and business documents alike.

Why can't the tool open my PDF?

The file may be damaged or password-protected. Encrypted PDFs must be unlocked with their password in a PDF editor first — this tool cannot open them, and it cannot remove a password.
