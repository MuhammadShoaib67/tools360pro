How to use the Resize Image tool

  1. Drop a JPG, PNG or WebP image onto the box above, or click to browse.
  2. Type a new width or height — with the aspect ratio locked, the other dimension follows automatically. Or use a percentage preset.
  3. Choose an output format if you want one, then check the live preview.
  4. Download the resized image.

Frequently asked questions

Is my image uploaded anywhere?

No. Resizing is done on a canvas in your browser. Your image never leaves your device.

Can I enlarge an image with this tool?

Yes — up to 200% with the presets, or any size you type. Note that enlarging cannot add detail that was not in the original, so large upscales will look softer.

What does “lock aspect ratio” do?

It keeps the width-to-height proportion the same as the original, so the picture is never stretched or squashed. Turn it off only if you deliberately want to change the shape.

Which size do social platforms need?

Common sizes: Instagram posts 1080×1080, YouTube thumbnails 1280×720, X (Twitter) posts 1600×900, Facebook posts 1200×630. Type the numbers straight into the width and height boxes.
