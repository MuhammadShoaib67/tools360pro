How to use the Resize Image tool

  1. Drop a JPG, PNG or WebP image onto the box above, or click to browse.
  2. Type a new width or height — with the aspect ratio locked, the other dimension follows automatically. Or use a percentage preset.
  3. Choose an output format if you want one, then check the live preview.
  4. Download the resized image.

Resizing without ruining your image

The golden rule is to shrink freely but enlarge carefully. Making an image smaller almost never hurts quality, while making it bigger stretches the existing pixels and can look soft or blocky — this tool allows up to 200%, but the result depends on the original. Keeping the aspect ratio locked stops faces and logos from looking stretched or squashed.

Everyday uses include shrinking a phone photo so it fits an application form's size limit, matching the exact pixel size a website asks for, or preparing images for social media, where every platform crops differently. If file size matters more than dimensions, compressing the image afterwards squeezes it further without changing how big it appears on screen.

Frequently asked questions

Is my image uploaded anywhere?

No. Resizing is done on a canvas in your browser. Your image never leaves your device.

Can I enlarge an image with this tool?

Yes — up to 200% with the presets, or any size you type. Note that enlarging cannot add detail that was not in the original, so large upscales will look softer.

What does “lock aspect ratio” do?

It keeps the width-to-height proportion the same as the original, so the picture is never stretched or squashed. Turn it off only if you deliberately want to change the shape.

Which size do social platforms need?

Common sizes: Instagram posts 1080×1080, YouTube thumbnails 1280×720, X (Twitter) posts 1600×900, Facebook posts 1200×630. Type the numbers straight into the width and height boxes.

What is the difference between resizing and compressing?

Resizing changes the pixel dimensions of an image. Compressing keeps the same dimensions but reduces the file size. Forms often limit one or the other — sometimes both.

Why does my resized image have a different file size?

Fewer pixels means less data, so a smaller image usually becomes a lighter file too. The exact size also depends on the format you choose — WebP is usually the smallest.
