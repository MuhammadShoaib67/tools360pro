How to use the QR Code Generator

  1. Enter a URL or any text in the box — the QR code updates live as you type.
  2. Choose a download size and adjust the foreground and background colours if you like.
  3. Check the preview and test it by scanning with your phone camera.
  4. Download your QR code as a PNG for everyday use or SVG for crisp printing at any size.

Frequently asked questions

Is my text or data uploaded?

No. Your QR code is generated entirely in your browser. The text or link you enter is never uploaded to a server or stored anywhere.

Do these QR codes expire?

No. These are static QR codes that encode your text or link directly, so they keep working for as long as the destination link itself works. There is no tracking or redirect in between.

PNG or SVG — which should I download?

Use PNG for websites, documents and social posts. Use SVG for print, posters and signage, because it stays perfectly sharp at any size.

Why will my QR code not scan?

Make sure there is enough contrast between the foreground and background colours — dark modules on a light background scan most reliably. Very long text also creates a denser code that needs a larger print size.

How much text can a QR code hold?

It depends on the content, but roughly up to a few thousand characters. Shorter links make smaller, easier-to-scan codes, so shorten long URLs first where you can.
