URL & HTML Encoder

Percent-encode text for URLs, decode it back, or convert special characters to and from HTML entities.

How to use the URL & HTML Encoder

  1. Choose URL or HTML entities using the toggle at the top.
  2. Type or paste your text into the Input box.
  3. Click Encode to convert it, or Decode to convert it back — in URL mode you can also tick the full-URL option to keep : / ? & = intact.
  4. Click Copy output to copy the result, or Swap to move the output back into the input.

Frequently asked questions

Is my text uploaded to a server?

No. Encoding and decoding run entirely in your browser using JavaScript. Your text is never uploaded, stored, or sent anywhere.

What is the difference between the URL and full-URL modes?

Normal URL encoding (encodeURIComponent) encodes characters such as : / ? & and =, which is right for a single value inside a query string. The full-URL option (encodeURI) leaves those structural characters intact, which is right when you are encoding a complete URL.

Why did URL decoding fail?

Decoding expects valid percent-encoded text, where every % is followed by two hexadecimal digits and the bytes form valid UTF-8. Plain text with a stray % sign will fail — encode it first, or remove the stray characters.

Which characters does HTML encoding convert?

It converts & to &amp;, < to &lt;, > to &gt;, a double quote to &quot;, and a single quote to &#39;. Decoding also understands &apos;, &nbsp;, decimal entities such as &#123;, and hex entities such as &#x1F600;.

When should I encode HTML entities?

Encode text before placing it inside HTML markup so characters such as < and & are displayed as text instead of being interpreted as tags or entity references.
