What the numbers mean

Dimensions are the image's size in pixels — width first, then height. A photo of 4000 × 3000 has 4000 pixels across and 3000 down. Megapixels are the total: width times height, divided by a million. That 4000 × 3000 photo is 12 megapixels. More megapixels mean more detail, and also a bigger file.

Aspect ratio is the shape: the width and height reduced to their smallest whole numbers. A 1920 × 1080 image is 16:9; a 1000 × 1000 image is 1:1. The ratio decides where the image fits — a 16:9 photo fills a widescreen slide, a 1:1 photo fills an Instagram post. Orientation is the plain-language version: landscape (wider than tall), portrait (taller than wide) or square.

When dimensions decide what you can do

Dimensions are a hard limit. An image can be shrunk to any smaller size without losing visible quality, but enlarging it beyond its pixel dimensions only spreads the existing pixels thinner — it never adds detail. Before printing, uploading or submitting an image, check whether it has enough pixels for the job: a 4 × 6 inch print at 300 dpi needs 1200 × 1800; a Full HD screen needs 1920 × 1080.

Forms and uploaders often reject images that are too small or too large, and their error messages rarely say why. Checking first saves the guesswork: if a form wants at least 1000 pixels and your image is 800 wide, you know the problem before uploading. If it is too large, the Compress Image tool shrinks the file without changing the dimensions.

File size vs dimensions

File size and dimensions are related but not the same thing. Two images with identical dimensions can differ tenfold in file size: a detailed photo compresses poorly, while a simple graphic with flat colours compresses to almost nothing. Format matters too — the same picture saved as PNG can be several times larger than as JPG, because PNG keeps every pixel exactly while JPG discards detail the eye barely notices.

That is why both numbers matter. Dimensions tell you whether the image is big enough for the job; file size tells you whether it will upload quickly or eat into a storage limit. If the dimensions are right but the file is too heavy, compress it. If the file is light but the dimensions are too small, no amount of compression will help — you need a larger original.

Frequently asked questions

Are my images uploaded to a server?

No. The image is read in your browser to measure it. Nothing is uploaded, stored or changed.

What is the difference between dimensions and file size?

Dimensions are the image's size in pixels (width × height). File size is how much storage the file takes (KB or MB). Two images with the same dimensions can have very different file sizes, depending on detail and format.

How many megapixels do I need for printing?

For a sharp print at 300 dpi, you need 300 pixels per inch of printed size — 1200 × 1800 for a 4 × 6 inch print (2.2 MP), 2400 × 3000 for 8 × 10 (7.2 MP). Fewer pixels still print, just softer.

Why does my phone photo say a different size than expected?

Phones often save photos larger than the screen shows, and some save a smaller preview alongside the full image. This tool measures the actual file you drop in, so the numbers are the file's real dimensions.

Can I check an SVG file?

Yes, if the SVG declares a width and height or a viewBox — the tool reads the rendered size. An SVG with no size information at all reports the browser's default rendering size, which is not a property of the file itself.

My image is too small for what I need — what now?

Enlarging it with the Image Enlarger makes it bigger in pixels but not sharper. For a genuinely small image, the AI Image Upscaler reconstructs detail instead of merely stretching pixels.
