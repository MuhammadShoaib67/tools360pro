How QR code scanning works in your browser

A QR code is a grid of black and white squares that encodes text. This scanner draws your image onto a canvas, reads the pixels, and hands them to a decoder library called jsQR, which finds the three square markers in the corners of the code, works out the grid, and reads the data — all in JavaScript, on your device. Nothing is uploaded: the image never leaves the page.

The decoder handles the most common QR code contents: web links, plain text, email addresses, phone numbers, Wi-Fi network details, and contact cards. If the decoded text is a web address, an Open link button appears so you can visit it directly. If it is anything else, you can copy the text with one click.

Why some QR codes do not scan

The most common reason is image quality. A blurry photo, a code photographed at a steep angle, or a code that is partly covered can all defeat the decoder, because it needs to see the corner markers and the grid clearly. Very small codes in a large image are another problem — the decoder works best when the code fills a good part of the frame.

If a scan fails, try cropping the image so the code is large and centred, straighten it if it is tilted, and make sure the lighting is even — glare and shadows break the black-and-white contrast the decoder relies on. Damaged codes sometimes still work, because QR codes carry error correction, but a code with a missing corner marker usually cannot be read at all.

What a QR code can contain

Most QR codes hold a web link, but the format can store up to about 4,000 characters of text. Restaurants use them for menus, shops for product pages, and events for tickets. Wi-Fi QR codes store a network name and password so a phone can join without typing. Contact QR codes store a name, phone number and email as a digital business card.

That flexibility is also why caution matters. A QR code can point anywhere, and you cannot tell where it leads just by looking at it — which is exactly why a scanner that shows you the link before you open it is useful. Read the decoded text first, and only open links that go where you expect.

Frequently asked questions

Is my image uploaded anywhere?

No. The scan runs entirely in your browser. Your image is drawn onto a canvas and decoded locally — it is never sent to a server, stored, or shared.

Can I scan a QR code with my camera?

Not with this tool — it reads QR codes from image files you upload. If your code is on paper or a screen, take a photo or screenshot of it first, then upload that image here.

What if the scanner finds no QR code?

The image may be too blurry, too small, tilted, or partly covered. Crop it so the code is large and centred, straighten it, and try again. Very damaged codes, especially with a missing corner marker, cannot be read.

What kinds of content can a QR code hold?

Web links, plain text, email addresses, phone numbers, Wi-Fi network details and contact cards are the most common. This scanner shows you the decoded text either way, so you can read it before deciding what to do with it.

Is it safe to open a link from a QR code?

Read the decoded link first. Only open it if the address looks like the site you expect. QR codes can point anywhere, so a scanner that shows the destination before you visit it is the safe way to check an unknown code.

Can I scan a QR code from a screenshot?

Yes — take a screenshot of the code on your screen, then upload the screenshot here. The scanner reads it exactly as it reads a photo, and shows the link or text inside with buttons to copy it or open it.

What image formats can I upload?

PNG, JPG, WebP or any common image format your browser can open. Screenshots, phone photos and downloaded images all work — if the image opens in your browser, the scanner can try to read the code inside it.

Can it scan a QR code on paper?

Take a photo of the code first, then upload the photo here. The scanner reads QR codes from image files, not from a camera, so a clear photo of the paper code works exactly like a screenshot.
