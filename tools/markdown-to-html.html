The subset this converter covers

This converter handles the Markdown people actually write every day: headings from # to ######, paragraphs, bold with ** or __, italic with *, links, images, unordered and ordered lists, fenced code blocks with an optional language tag, inline code, blockquotes and horizontal rules. That covers the great majority of blog posts, notes and documentation pages.

What it does not cover is stated plainly, so there are no surprises. Tables, footnotes, strikethrough, task lists and nested lists are not supported — a nested list will be flattened to one level. Raw HTML inside your Markdown is escaped and shown as text, not passed through. If you need the full CommonMark spec, a dedicated library or a tool like Pandoc is the right call.

Why convert Markdown to HTML?

Markdown is a writing format; HTML is a publishing format. The conversion is needed whenever the destination only accepts HTML: a CMS that has no Markdown editor, an email newsletter, an old website template, or a page builder that takes raw HTML blocks. Writing in Markdown and converting at the end keeps the source readable while the output stays compatible.

It is also the fastest way to preview a document. Paste a README or a draft post, convert it, and the preview panel shows how it will look when rendered — headings, lists and code blocks included — without committing anything or opening a separate editor.

Markdown lives in more places than most people realise. GitHub renders it in README files and issues, note apps like Obsidian and Notion use it as their native format, and many documentation systems are built on it. When that content has to move somewhere that only understands HTML — a company intranet, an email campaign, a legacy website — a converter is the bridge, and the preview panel is the check that the bridge held.

Markdown basics in thirty seconds

A heading is one or more # characters followed by a space. Bold is **text**, italic is *text*, and code is `text`. A link is [text](url) and an image is the same with a ! in front. Lists start with - or a number followed by a dot, and a code block is three backticks on a line of their own.

Blank lines matter: they separate paragraphs and end lists. Two lines of text with no blank line between them become one paragraph, which is usually what you want for a wrapped sentence. If your output merges two blocks you meant to keep apart, a blank line between them is almost always the fix.

Frequently asked questions

Does it support tables?

No. Tables are not part of the supported subset, and a table written in Markdown will come out as plain paragraphs. For documents with tables, use Pandoc or a full Markdown library.

What happens to raw HTML in my Markdown?

It is escaped and shown as text, not passed through as markup. That keeps the output safe, but it means HTML embedded in Markdown will not render.

Can it handle nested lists?

No, only single-level lists. A nested list is flattened: the inner items appear at the same level as the outer ones. Keep lists flat for the best result.

Is the output valid HTML?

Yes. The converter emits standard tags with escaped text, so the output can be pasted into any page, CMS or email template without breaking the surrounding markup.

Is my text uploaded anywhere?

No. This tool runs entirely in your browser using JavaScript. Your text is never uploaded, stored or sent anywhere — everything stays on this device.

Which Markdown syntax does it support?

Headings from # to ######, paragraphs, bold and italic, links, images, unordered and ordered lists, fenced code blocks with language tags, inline code, blockquotes and horizontal rules. Tables, footnotes, strikethrough, task lists and nested lists are not supported.

Can I see the HTML before I copy it?

Yes — the live preview shows the converted page as it will render, and the HTML output sits beside it. Check the preview first: if something looks wrong, it is usually a piece of syntax outside the supported subset.

Can I convert HTML back to Markdown?

Not with this tool — it converts one way, from Markdown to HTML. For the opposite direction there is a separate converter on this site that turns HTML into Markdown.
