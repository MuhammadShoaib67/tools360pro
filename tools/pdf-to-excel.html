What makes a table convert cleanly

The cleanest conversions come from PDFs that were exported from a spreadsheet or a report writer — Excel, Google Sheets, Word, or a university results portal — where every column starts at the same x position on every row. The converter reads the position of each piece of text, groups the pieces into rows, and works out the columns from where the text lines up. A table with a header row, short cell text and clear gaps between columns usually lands in Excel exactly as it looked in the PDF.

Three things make detection harder. Merged cells — one cell spanning two columns, like a title row across a table — have no column of their own, so their text lands in the leftmost column they cover. Cells whose text wraps onto a second line are usually stitched back together, but a wrap in the first column can look like a new row. And tables with almost no gap between columns, or with centred text, give the detector very little to work with. In all three cases the preview editor is the fix: the .xlsx is built from the preview, not from the first guess.

Fix it in the preview before you download

Every detected table opens as an editable grid, with the first row treated as the header. Click any cell and type to correct it — a number that landed in the wrong column, a name split across two cells, a wrapped sentence that needs joining back up. If a table was detected that is not really a table (a two-column list of labels, for example), untick its checkbox and it will not be exported at all.

When you download, each checked table becomes its own sheet, named after its table number and the page it came from, so a long report keeps its tables separate instead of stacking them into one confusing sheet. Numbers stay numbers in Excel, so you can sort, filter and run formulas on them straight away; the header row is bold with a light fill, and column widths follow the longest value in each column.

Frequently asked questions

Which PDFs work best?

Text-based PDFs with clear tables: exported from Word, Excel, Google Sheets or a report writer, where you can select and copy the text with your mouse. Tables with lined-up columns and one header row convert most cleanly; a table whose text is centred or whose columns run together is harder to read and may need a few fixes in the preview.

My PDF is a scan. Will it work?

No — a scanned PDF is a picture of pages and contains no text to read, so this converter will tell you it found no text layer. Turn the pages into images with our PDF to Image tool, then read them with our Image to Text (OCR) tool instead.

Why did a table come out wrong?

A PDF stores where every letter sits, not what the table means, so the converter has to guess the columns from the positions of the text. Merged cells, cells that span columns, and tables with no clear gaps between columns can all confuse it. That is why every table opens in an editable preview first — fix any cell there before you download, and the .xlsx will contain exactly what you see.

Can I choose which tables to export?

Yes. Every detected table has its own checkbox in the preview — untick any table you do not want. Each exported table becomes one sheet in the .xlsx file, named after its table number and page, so a ten-page report keeps its tables separate and easy to find.

Is my PDF uploaded anywhere?

No. The PDF is read and the Excel file is built entirely in your browser tab. Your document never leaves your device, so statements, reports and personal files stay private.
