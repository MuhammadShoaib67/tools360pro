How to use the Open Graph Preview Tool

  1. Type the og:title, og:description and og:image URL exactly as they will appear on your page.
  2. Add the page URL and site name, and pick the type: article for posts, website for everything else.
  3. Watch the Facebook and X preview cards update as you type, and check the image loads.
  4. Copy the meta tags from the box at the bottom and paste them into the head of your page.

What Open Graph tags do

When someone shares a link on Facebook, X, LinkedIn or in a chat app, the platform builds a preview card from the page: an image, a title and a short description. Open Graph tags are the meta tags that control that card. Without them, the platform guesses, and the guess is often the wrong image or a fragment of navigation text. With them, you choose exactly what the card shows.

The four tags that matter most are og:title, og:description, og:image and og:url, with og:type and og:site_name adding context. X reads Open Graph tags as a fallback, but adding a twitter:card tag with the value summary_large_image makes the large image explicit. This tool generates all of them from the values you type, so you can paste the finished block into your page head.

The image is the hard part

The recommended Open Graph image size is 1200 by 630 pixels, which fills the large card on Facebook and X without cropping. Smaller images still work, but they may be shown small or stretched, and Facebook will not accept an image smaller than 200 by 200 pixels. The image URL must be absolute, starting with https://, and the file must be publicly reachable: a relative path or a localhost address will show nothing.

Text on the image should be large and short, because the card is often seen at phone width. Keep the important words away from the edges, where cropping bites first, and test the image at small size before publishing: if the title is unreadable in the preview, it will be unreadable in the feed.

Why the preview does not fetch your page

This tool renders the preview from the values you type. It does not fetch your URL, because a static web page cannot fetch other websites: browsers block cross-origin requests from pages like this one. The preview you see here is a faithful mock of the card layout, but the final check belongs to the platforms themselves.

After publishing, paste the URL into the Facebook Sharing Debugger and the X Card Validator. Both show what the platform actually scraped, and both refresh the cached version, which matters because Facebook and X cache link previews: if you shared a link before the tags were right, the old preview can linger until the debugger forces a re-scrape.

Frequently asked questions

Does this tool fetch my URL?

No. It renders the preview from the values you type, because a static page cannot fetch other websites. Use the Facebook Sharing Debugger or the X Card Validator to check the live page.

What size should the OG image be?

1200 by 630 pixels is the recommended size for both Facebook and X. The URL must be absolute and public, and the file must be reachable without a login.

Why does the shared link show the wrong image?

Usually a cached scrape: the platform stored the old preview. Use the platform debugger to refresh it, and check that the image URL is absolute, public and at least 200 by 200 pixels.

Do I need Twitter card tags too?

X reads Open Graph tags as a fallback, but adding twitter:card with summary_large_image makes the large image explicit. This tool includes those tags in the copied block.

Is my data uploaded anywhere?

No. This tool runs entirely in your browser using JavaScript. Nothing you type is uploaded, stored or sent anywhere. The image preview loads the image URL in your own browser only.
