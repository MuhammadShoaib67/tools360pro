What this checker looks at

On-page SEO starts with a short checklist, and this tool runs through it. The title and the meta description are measured for length, because both are truncated in the search results when they run long. The headings are counted, because a page should have exactly one H1. The primary keyword is checked in the title, the description, the H1 and the body, because those are the places search engines weigh when they work out what a page is about.

Two more checks round the list out. Word count is a rough measure of whether the page says enough to be useful: a page of fifty words rarely answers a query well. Readability is judged by average sentence length, which is a crude but honest signal — pages written in long, dense sentences are harder to scan, and scanning is how most people read on the web.

Why one H1, and why keyword placement matters

The H1 is the main heading of the page, and the long-standing convention is one per page. HTML5 technically allows more, and Google can cope with several, but one H1 keeps the structure clear: one page, one topic, one main heading, with H2 and H3 headings breaking the content into sections below it. When a page has three H1s, it usually means the page is trying to be three pages at once.

Keyword placement is about the same idea: the places a reader looks first are the places a search engine weighs most. A keyword in the title, the H1 and the first paragraph tells both audiences, quickly, what the page covers. That does not mean repeating it until the text sounds unnatural — one natural mention in each spot is enough, and the body check in this tool flags densities above three percent as a warning, not a goal.

What this checker cannot do

This is a draft checker, not an audit. It sees only the text you paste: it cannot check whether the page is indexed, whether other sites link to it, how fast it loads, whether the images have alt text, or whether the published page matches the draft at all. Those checks need the live page and tools built for them, such as Google Search Console for indexing and PageSpeed Insights for speed.

Use this tool early, while the page is still a draft, when fixes are cheap: a title rewritten before publishing costs nothing, and a heading structure fixed in the draft never ships broken. Then verify the published page separately, and treat this checklist as the floor of good on-page SEO, not the ceiling.

Six checks before you publish: length, H1, keyword, words, readability

The checklist covers the basics every page needs: is the title the right length, is the meta description the right length, is there exactly one H1, and does the primary keyword appear in the title, the description, the H1 and the body? Word count and readability — measured by average sentence length — complete the picture, so a draft that is too thin or too hard to read is flagged before it goes live.

Each check passes, warns or fails, and a summary shows how many passed, how many need attention and how many failed — fix the failures first, then the warnings, and check again; the summary updates every time. What it deliberately does not do is just as important: it does not crawl anything, fetch a URL or see your published page, and it does not check indexing, backlinks, page speed or image alt text. For those, use Google Search Console and PageSpeed Insights — this tool is the floor, not the ceiling.

Frequently asked questions

Is this a full SEO audit?

No. It checks a pasted draft against a basic on-page checklist. A full audit needs the live page, its links, its speed and its indexing data, which only tools like Search Console can see.

Why exactly one H1?

One main heading per page keeps the structure clear for readers and crawlers. Several H1s are valid HTML5, but they usually mean the page is trying to cover too many topics at once.

Does keyword density matter?

Only as a sanity check. The keyword should appear in the title, H1 and body, but repeating it until the text sounds unnatural hurts readers and can look like stuffing.

What word count should a page have?

Enough to answer the query well. Three hundred words is a reasonable floor for a page that wants to rank, but thin pages fail on usefulness, not on a number.

Is my data uploaded anywhere?

No. This tool runs entirely in your browser using JavaScript. Nothing you paste is uploaded, stored or sent anywhere.

What does the checker look at in my title and meta description?

Their length: a title that is too long gets cut off in search results, and a description that is too long is truncated too. The checker flags both, so you can trim them to fit before the page is published.

How does it check keyword placement?

It looks for your primary keyword in the four places that matter most: the title, the meta description, the H1 and the body text. A keyword that appears in all four is a good sign; one missing from the title or H1 is worth fixing.

Can this tool check my published page?

No — it checks the draft text you paste, not a live page. It does not crawl anything, fetch a URL or see your published page. For indexing, links and speed, use Google Search Console and PageSpeed Insights.
