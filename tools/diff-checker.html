How to use the Diff Checker

  1. Paste the original text on the left and the new version on the right.
  2. Press Compare — green lines were added, red lines were removed.
  3. Tick "Show changes only" to hide the unchanged lines and read just the edits.

Spot the edit in seconds, not by reading twice

Someone sends back a "slightly updated" contract, a student revises an essay, a teammate tweaks a configuration file — and the real question is always the same: what actually changed? Reading both versions side by side and hoping to catch every edit is slow and unreliable; one altered number in a price clause is easy to stare straight past. A diff does the staring for you, lining the two texts up and flagging every line that was added, removed or moved.

This checker uses the same line-matching method (longest common subsequence) that powers the diff views in professional code tools, with a view anyone can read: plus for new, minus for gone. Because it runs in your browser, you can safely compare the documents you would never paste into a random server — drafts, agreements, unpublished writing and private code.

This task often leads to two others: Regex Tester tests regular expressions against sample text, and Text Cleaner removes duplicate lines, extra spaces and stray formatting.

Frequently asked questions

How does the comparison work?

The two texts are compared line by line using the same longest-common-subsequence method programmers use for code. Lines only in the second text are marked as additions (+), lines only in the first as deletions (−).

Can I compare code with it?

Yes — it works for any plain text: source code, configuration files, essays, contracts, product descriptions or lists. Formatting and spacing within a line are treated exactly as typed.

How much text can I compare?

Up to about 3,000 lines on each side — far more than most documents. Very large files are better compared in a desktop code editor.

Is my text uploaded or stored?

No. The comparison runs entirely in your browser tab, so contracts, drafts and code stay on your device.
