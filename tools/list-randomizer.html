How to use the List Randomizer

    
  1. Type or paste your list in the box, with one item on each line — blank lines are ignored and the item count updates as you type.
  2. Click Shuffle list to put every item into a random order, or set how many winners to pick and click Pick winners.
  3. Use the numbering option to turn line numbers like “1. item” on or off in the result.
  4. Copy the result exactly as shown, or download it as a .txt file.

  

  

    
Frequently asked questions

    
How random is the shuffle?
The shuffle uses the Fisher–Yates algorithm with randomness from your browser's cryptographic generator (crypto.getRandomValues) and rejection sampling, so every ordering is equally likely and there is no bias towards any position.

    
Can the same item win twice when I pick winners?
No. Winners are picked without replacement: the list is shuffled and the first N items are taken, so each entry can only be picked once in a single draw.

    
What happens to duplicate lines and blank lines?
Blank lines are ignored. Duplicates are kept as separate entries — if the same name appears on two lines, it counts as two entries and could appear twice in a shuffled list or win as either entry. Remove duplicate lines first if you want each item to count only once.

    
What does Copy copy — with or without the numbers?
Copy copies exactly what is displayed in the result box, including the line numbers when numbering is switched on. Turn numbering off before copying if you want the plain items only.

    
Is my list uploaded anywhere?
No. Your list is shuffled and picked entirely in your browser. Nothing is uploaded, logged or stored — the list disappears when you leave the page.
