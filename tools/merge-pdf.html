How to use the Merge PDF tool

  1. Drop two or more PDF files onto the box above, or click it to browse your device.
  2. Use the up and down arrows on each file to set the order the documents should appear in.
  3. Press Merge PDFs — the combined file is built right in your browser.
  4. Download the merged PDF. Your originals are never modified or uploaded.

Frequently asked questions

Are my PDF files uploaded to a server?

No. The merge happens entirely in your browser using JavaScript. Your files never leave your device, and nothing is stored anywhere.

How many files can I merge at once?

There is no fixed count limit — you can add as many PDFs as you like. Very large batches are limited only by your device's memory, because everything is processed locally.

Will the quality of my PDFs change?

No. Pages are copied into the new document exactly as they are — text, images and vector graphics keep their original quality.

Can I change the order before merging?

Yes. Every file in the list has up and down arrows so you can arrange the documents in any order before you merge.

One of my files won't load. Why?

The file may be corrupted or password-protected. Encrypted PDFs need to be unlocked with their password in a PDF editor first — this tool cannot open them.
