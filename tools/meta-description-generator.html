What a meta description does

A meta description is the short pitch that appears under a page title in the search results. It is not a ranking factor — Google has said so plainly — but it is the text that persuades a searcher to click your result instead of the one above or below it. A clear, specific description earns more clicks; a missing or generic one leaves the decision to chance, and Google will often substitute text from the page instead.

Because the description is advertising copy for the page, it should match what the page actually delivers. A description that promises a free guide should lead to a free guide, and a description that names a price should name the right one. Searchers who feel misled bounce back to the results, and a high bounce rate helps nobody.

Length: the 150 to 160 character window

Google shows roughly 155 to 160 characters of a description on desktop, and less on mobile, before cutting it off with an ellipsis. A description much shorter than 120 characters wastes space that could have carried a reason to click; a description much longer than 160 gets its ending chopped off, which is where the call to action usually sits. The practical target is 150 to 160 characters, with the most important words in the first half in case the rest is cut.

This tool counts characters for every suggestion and flags anything outside the window. Remember that the count is a guide, not a guarantee: Google truncates by pixels, and it sometimes shows a longer description for a query that matches the later words. Write for the window, and put the promise early.

Writing descriptions people click

The strongest descriptions are specific: they name what the page covers, who it is for, and what the reader gets. Compare a generic description such as a page about coffee with one that says what the page teaches and who it helps, and the choice is obvious. One clear promise beats three vague ones, and the primary keyword should appear naturally once, near the start, so it is bolded in the results when it matches the query.

Avoid keyword stuffing, all-caps shouting and claims the page cannot back up. And write a different description for every page: duplicated descriptions across a site are a common reason Google ignores them and picks its own text from the page instead.

Frequently asked questions

How long should a meta description be?

Aim for 150 to 160 characters. Google truncates longer descriptions in the search results, and much shorter ones waste space that could carry a reason to click.

Does the meta description affect rankings?

Not directly: Google has confirmed the meta description is not a ranking factor. It affects click-through rate, which is the reason to write a good one.

Are these descriptions written by AI?

No. They come from proven templates filled with your keyword. Edit the result until it describes your page exactly: templates give structure, your content gives meaning.

Why does Google sometimes show different text?

Google may replace your description with text from the page when it thinks its own snippet matches the search query better, or when the description is missing or duplicated across pages.

Is my data uploaded anywhere?

No. This tool runs entirely in your browser using JavaScript. Nothing you type is uploaded, stored or sent anywhere.

What should a meta description say?

The benefit of clicking: what the page covers and why it is worth opening, in plain language, with the keyword included naturally. A call to action helps — learn, compare, try — and the 150 to 160 character window is enough for one clear promise, not three.

Can I use the same meta description on every page?

No — every page needs its own description. Duplicate descriptions make pages look the same in the search results, and searchers skip them. Run each page's keyword through the generator for a fresh description that fits that page.

What is the SERP snippet preview for?

It shows your description the way Google shows it in the search results, so you can see truncation and wasted space before the page goes live. A description that looks complete in the preview is one searchers will read in full.
