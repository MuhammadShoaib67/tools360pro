Frequently asked questions

    
Is my data uploaded or stored?
No. UUIDs are generated locally in your browser with the Web Crypto API. Nothing is uploaded, logged, or stored on any server.

    
What is a UUID v4?
A UUID (Universally Unique Identifier) is a 128-bit identifier. Version 4 UUIDs are generated from random numbers, with the version and variant bits set so the pattern is xxxxxxxx-xxxx-4xxx-yxxx-xxxxxxxxxxxx where y is 8, 9, a, or b.

    
Can two generated UUIDs ever be the same?
In practice, no. With 122 random bits, the chance of a collision is astronomically small — you would need to generate billions of UUIDs before a duplicate becomes likely.

    
What happens if I turn Hyphens off?
The hyphens are stripped for display, giving a 32-character hex string. The underlying UUID value is the same; some systems prefer the compact form.

    
Where are UUIDs used?
UUIDs are commonly used as database primary keys, session IDs, transaction IDs, file names, and distributed-system identifiers where a central counter is not practical.
